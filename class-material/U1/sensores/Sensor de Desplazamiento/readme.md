### Introducción
Los sensores de desplazamiento son dispositivos utilizados para medir cambios en la posición de un objeto. Estos sensores convierten el movimiento lineal en una señal eléctrica que puede ser interpretada y procesada por sistemas de control. Existen varios tipos de sensores de desplazamiento, entre los cuales destacan el LVDT (Transformador Diferencial Variable Lineal) y el Potenciómetro Lineal.

### **LVDT (Transformador Diferencial Variable Lineal)**

#### **Principio de Funcionamiento**
El LVDT es un sensor inductivo que consiste en un devanado primario y dos devanados secundarios montados en un núcleo ferromagnético móvil. Cuando el núcleo se desplaza dentro del sensor, se genera una diferencia de voltaje proporcional al desplazamiento.

#### **Ventajas**
- Alta precisión y repetibilidad.
- Funcionamiento sin contacto, lo que reduce el desgaste mecánico.
- Amplio rango de mediciones.
- Resistencia a ambientes hostiles.

#### **Aplicaciones**
- Sistemas de control en aviación y automoción.
- Medición de desplazamiento en maquinaria industrial.
- Pruebas de materiales y estructuras.

### **Potenciómetro Lineal**

#### **Principio de Funcionamiento**
El potenciómetro lineal es un sensor resistivo que mide desplazamientos mediante un contacto deslizante que se mueve a lo largo de una pista resistiva. A medida que el contacto cambia de posición, la resistencia varía y genera un voltaje proporcional al desplazamiento.

#### **Ventajas**
- Diseño simple y bajo costo.
- Salida de señal directa y fácil de interpretar.
- Compacto y fácil de integrar en sistemas pequeños.

#### **Aplicaciones**
- Control de posición en equipos industriales y robótica.
- Sensores en sistemas de suspensión de vehículos.
- Dispositivos médicos para medición de movimiento.

### **Comparación entre LVDT y Potenciómetro Lineal**
| Característica  | LVDT | Potenciómetro Lineal |
|-----------------|------|------------------|
| Principio de Funcionamiento | Inductivo | Resistivo |
| Contacto físico | No | Sí |
| Precisión | Alta | Media |
| Durabilidad | Alta (sin desgaste) | Media (por fricción) |
| Costo | Alto | Bajo |
| Aplicaciones | Industrial, automoción | Electrónica, robótica |

### **Conclusión**
Tanto el LVDT como el potenciómetro lineal son sensores de desplazamiento efectivos, pero su elección depende de la aplicación específica. Mientras que el LVDT ofrece alta precisión y durabilidad para entornos exigentes, el potenciómetro lineal es una solución económica y sencilla para mediciones menos críticas. La selección del sensor adecuado dependerá de factores como el presupuesto, la precisión requerida y las condiciones operativas.
